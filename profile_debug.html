Open-Deck Profile Loader

Use this page to import/export profile data (including column layouts).
This is useful when moving to a new prototype release.
Input/output format is JSON. Invalid data may not work correctly.
If you imported invalid data, use `Debug` -> `init settings` to reset.

Export Profile

Click the `Export Profile` button to output column settings.
The data appears in the text area below the button. Save it after export.
You can import this exported profile in the section below.

Output

Import Profile

Paste a profile into the text area below, then click `Import`.
This will load column configuration and related settings.

Profile JSON Input

The input profile is from prototype versions up to v1.0.5
