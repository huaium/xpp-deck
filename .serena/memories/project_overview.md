# Open-Deck Project Overview

- Purpose: Browser extension (Open-Deck) that provides a Deck-style multi-column UI for X/Twitter, including timeline/notification/explore columns, profile layouts, and extension helpers (text review, media viewer controls, auto reload).
- Targets: Chromium-based browsers (Manifest V3 via `manifest.json`) and Firefox (Manifest V2 via `manifest_firefox.json`).
- Primary runtime model: Content script + background script extension architecture.
- Localization: `_locales/ja/messages.json` and `_locales/en/messages.json`.
- Packaging/release flow: ZIP artifacts generated by `package.sh` (macOS/Linux) or `package.ps1` (Windows), with GitHub Actions release workflow in `.github/workflows/release.yml`.
