# Text Review Feature Privacy Policy

**Last Updated: October 23, 2025**  
**Applicable Version: 1.1.2 and later**

This extension provides a text review feature that sends user-entered post text to a text review server and returns revised output.  
This policy explains how that data is handled.

---

## What Data Is Sent

When the user clicks the text review button,  
only the body text of the tweet (post) entered by the user is temporarily sent to the server.  
No personal information (such as name, email address, or account information) is collected.

---

## Purpose of Use

The submitted text is used only to perform text review and return the result.

---

## Data Storage

The server does not store or log submitted text or review results.  
If you need to keep results, please save them on your own.

---

## Data Sharing

Data is not shared with or sold to third parties.  
_Exception: this does not apply when the user voluntarily provides feedback._

---

## Communication Security

HTTPS is used for all text transmission, and communication is encrypted.

---

## Revisions

This policy may be updated when features are added or specifications change.  
If there are major changes, we will announce them in extension update information or similar notices.
